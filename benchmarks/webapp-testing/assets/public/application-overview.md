# Workboard Lite 应用说明

**应用名称：** Workboard Lite  
**版本：** 0.1.0  
**来源类型：** SYNTHETIC  
**用途：** 作为 Web 应用测试能力的确定性本地测试对象  
**运行地址：** `http://127.0.0.1:4173`  
**认证：** 无  
**外部依赖：** 无  
**持久化：** 应用进程内存；服务重启后恢复初始数据

## 1. 应用范围

Workboard Lite 是一个单工作区任务看板。用户可以查看任务、搜索任务、筛选状态、创建任务、修改任务状态和删除任务。

应用仅用于测试。它不连接真实项目管理服务，不包含真实用户或生产数据。

## 2. 页面结构

首页包含：

- 任务总数、待处理数、处理中数和已完成数摘要。
- 任务搜索框。
- 状态筛选器。
- 任务列表，显示任务标题、说明、优先级和状态。
- 状态流转按钮。
- 删除按钮和确认对话框。
- 创建任务表单。
- 操作结果和错误提示。

## 3. 初始数据

应用启动时提供五条合成任务：

| ID | 标题 | 优先级 | 初始状态 |
|---|---|---|---|
| WB-101 | Reset password flow | High | Open |
| WB-102 | Update onboarding guide | Low | In progress |
| WB-103 | Fix export timeout | High | Done |
| WB-104 | Verify email notification | Medium | Open |
| WB-105 | Review accessibility | Medium | In progress |

任务描述也由应用提供，用于搜索和页面展示。完整数据以运行中的应用返回值为准。

## 4. 主要页面行为

- 打开首页后显示初始任务和摘要数量。
- 输入搜索词后更新任务列表。
- 修改状态筛选器后更新任务列表。
- 创建任务后显示新任务。
- 点击状态按钮后推进任务状态。
- 点击 Delete 后显示确认对话框。
- 点击 Cancel 关闭对话框，不删除任务。
- 确认删除后移除指定任务。

## 5. 数据和副作用边界

所有数据均为合成数据。状态仅保存在应用进程内存中。重启应用会重置任务。测试不得访问线上系统、真实账户、客户数据或外部 API。

应用实现是被测对象，不是业务规则的权威来源。期望行为以 `business-rules.md` 为准。应用代码只用于理解启动方式和接口结构；代码实现不能取代对实际 UI 行为的验证。
