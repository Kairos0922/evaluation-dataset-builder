# v0.0.2 量化公式构建与验证协议

**状态：** 预注册协议草案，尚未执行验证实验。  
**原则：** 本文定义如何证明候选公式能否支持预定解释和决策，不预先宣布某个公式有效。

## 1. 要证明的主张

任何综合分模型必须明确其主张范围，至少区分：

- M1：离线数据集质量画像能否识别设计、来源、目标对齐、任务可解性和判定契约中的已知缺陷。
- M2：离线分项或综合分能否预测真实运行中的测量有效性。
- M3-C：Capability 数据集能否可靠地区分目标能力水平，并在目标能力区间提供足够测量信息。
- M3-R：Regression 数据集能否发现已知真实缺陷/退化，同时控制误放行和误报。
- M4：公式在未参与开发的 Agent、Skill、任务域、模型和环境上是否保持可解释和稳定。

不同主张必须有各自的证据。不能用 M1 的静态规则通过证明 M2、M3 或 M4。

## 2. 测量构念与指标类型

在收集评分前，建立构念图：

质量主张 → 子构念 → 指标 → 数据来源 → 计算规则 → 解释 → 决策后果。

对每个指标分类：
- **形成性（formative）**：指标共同构成质量属性，指标之间不要求高度相关；例如来源可追溯、覆盖、任务可解性、判定契约正确性。
- **反映性（reflective）**：指标是同一潜在属性的表现；只有理论和数据均支持时才使用潜变量/内部一致性方法。
- **结果/效标指标（criterion）**：独立于评分模型，用于检验预测或决策效用，例如历史缺陷检出、Oracle 复核结果。
- **门禁（gate）**：不能被其他维度补偿的严重问题，例如错误金标准、不可执行任务、严重安全缺陷。
- **诊断指标（diagnostic）**：用于解释问题，不一定进入综合分。

不能因为所有指标都以 0–1 表示，就推断它们属于同一尺度或可以直接求平均。

## 3. 独立参考标准（Reference Standard）

不存在天然、无误的“数据集质量金标准”。采用三类互补参考证据，避免单一来源循环验证。

### 3.1 专家盲评参考

- 由具备 Agent/Skill、评测设计或目标业务经验的审查者独立审查。
- 评审者在首轮评分时看不到 Builder 自评、自动评分和候选综合分。
- 每份样本由多位审查者独立评分；分歧保留，不先强制压成一个标签。
- 记录评审者资历、利益冲突、培训材料、评审指南版本和仲裁过程。
- 报告内容效度、评分者间一致性和不确定性。

专家意见是重要证据，不被定义为绝对真理。若专家自身分歧较大，应降低结论强度并分析歧义来源。

### 3.2 控制缺陷注入参考

对一批基线数据集创建受控变体，每次只注入一种已知缺陷，另保留未修改对照组。

候选缺陷类别：
- 任务描述歧义、目标缺失、无关能力干扰；
- 错误或过期 Ground Truth；
- Rubric 与目标不一致、通过/失败条件不完整；
- 评分器接受空输出、忽略关键状态或错误地使用字符串匹配；
- 伪造/错配来源、来源版本或引用定位；
- 语义重复、模板重复、关键能力/风险覆盖缺失；
- 任务不可解、环境/工具/权限不匹配；
- 泄漏、答案提示、调优集与保留集污染；
- 运行环境随机性或 Judge 偏差。

每个变体都记录变异算子、目标字段、预期影响、独立确认和变异等价性审查。等价变异不计入缺陷检出分母。

### 3.3 真实运行效标参考

- 历史生产失败或已确认事故的回放；
- 独立 Gold Oracle 对任务完成与过程约束的判断；
- Agent/Skill 的真实重复运行；
- 新旧版本的配对回归结果；
- Capability 评测的跨模型/跨任务能力估计与测量精度；
- Judge 与独立人工判断的对照。

历史轨迹只证明发生过什么，不自动证明预期结果正确。每个真实故障必须有可审计的缺陷定义和独立确认。

## 4. 公式开发数据与验证数据隔离

数据集级切分，不允许随机拆散同一来源、同一任务模板或同一基准的近重复用例。

至少分为：
- **Development**：指标开发、模型探索、权重估计。
- **Validation**：模型选择、校准和阈值探索；仅在协议允许时使用。
- **Locked Test**：冻结后只用于最终一次确认性验证。
- **External Replication**：不同 Agent/Skill、领域、模型家族或环境的外部复现。

按 Dataset ID、来源家族、任务模板、目标领域和被测 Agent 进行分组，避免信息泄漏。切分单位和原因必须记录。若数据规模不允许独立外部验证，则不得声称跨领域泛化已被证明。

## 5. 候选公式比较

不先验指定唯一公式。至少比较以下模型族：

1. 门禁 + 多维画像，不产生总分；
2. 非补偿模型（关键维度不能由其他维度抵消）；
3. 线性加权模型；
4. 几何/乘法模型；
5. 分层或用途特定模型；
6. 在指标具有反映性且假设通过检验时，才考虑潜变量模型。

候选表达式：

S_m(D) = A_m(z_1(D), ..., z_k(D); theta_m)

其中 D 是指定数据集版本，z_j 是经定义和转换的指标，A_m 是候选聚合函数，theta_m 是待估参数。该表达式只表示候选模型族，不构成已选公式。

模型比较必须回答：
- 是否能识别已知注入缺陷？
- 是否预测独立专家审查和真实运行效标？
- 是否校准？
- 是否在不同任务域/Agent/Skill 上泛化？
- 是否对权重、指标和抽样扰动稳健？
- 是否保持可解释、可审计？
- 是否比简单的门禁 + 分项画像带来实际增量价值？

若复杂总分不能稳定优于简单分项画像，保留简单模型。

## 6. 预先定义的统计分析

### 6.1 专家效度与评分者一致性

根据数据类型选择统计量：
- 名义类别：Cohen's Kappa（两位评审）、Fleiss' Kappa 或 Krippendorff's Alpha（多评审/缺失设计）；
- 序数等级：加权 Kappa、序数 Krippendorff's Alpha；
- 连续分数：明确 ICC 模型、单次/平均测量、绝对一致/一致性定义；
- 内容效度：I-CVI、S-CVI 或 CVR，报告专家人数、项目级分布和置信区间。

同时报告原始一致率、混淆矩阵、类别分布和分歧类型。不能只报告一个 Kappa / ICC 数字。

### 6.2 候选公式预测效度

根据效标类型报告：
- 二元效标：Sensitivity、Specificity、Precision、Recall、F1、PR-AUC / ROC-AUC（视基率和用途）、Brier Score、校准曲线；
- 序数效标：加权 Kappa、序数回归、等级校准；
- 连续效标：MAE / RMSE、Pearson / Spearman、校准与残差分析；
- 排名/决策：排序稳定性、决策一致性和错误成本；
- 缺陷检出：按缺陷类别、严重度和数据集分组报告 False Pass / False Fail。

指标必须与预定决策相符。AUC 高不能替代校准，相关性高不能证明因果关系或低误放行风险。

### 6.3 不确定性和抽样

- 对任务嵌套于数据集、数据集嵌套于领域的结构，使用分层/聚类 Bootstrap 或适合的层级模型。
- 对重复运行，按 Agent × Task × Seed × Environment × Judge 建模；不能将相关运行当成独立样本。
- 置信区间、统计功效和样本量依据目标效应、变异、基率、聚类和决策风险规划。
- 不设跨任务通用的固定最小样本数。若样本不足，报告区间过宽或统计能力不足。

### 6.4 权重与聚合敏感性

对候选权重和聚合方案进行：
- 理论允许范围内的权重扰动；
- 指标删除/增加；
- 指标标准化方法替换；
- 缺失值机制和处理方式替换；
- 算术、几何、非补偿模型比较；
- Bootstrap 权重/参数分布；
- 数据集排序和等级决策变化分析。

报告总分变化、排名反转、门禁冲突、错误决策和不确定性来源。不能只报告“平均分变化不大”。

## 7. Capability 专属确认性分析

- 以 Agent × Task 响应矩阵为基础，检查 IRT 模型适配、局部独立、单维/多维结构、参数可识别性和样本条件。
- 题目难度和区分度用于描述测量属性，不直接等于数据集质量。
- 报告 Test Information Function、Conditional Standard Error、能力估计区间和排名不确定性。
- 对模型家族、语言、工具配置、领域等进行 DIF / 测量不变性检查。
- 通过已知组、基线能力和独立真实任务表现提供外部效度证据。
- 如果 IRT 假设不满足，使用适当的非参数或分层统计方法，不强行拟合。

## 8. Regression 专属确认性分析

- 同一任务、同一环境和尽可能相同的运行配置下进行新旧版本配对。
- 二元配对结果可使用 McNemar 检验或配对 Bootstrap；报告任务级变化与关键风险任务。
- 历史真实缺陷回放和受控变异缺陷分开报告。
- 变异检出分数只作为补充证据；真实故障检出必须独立测量。
- Flakiness 需要重复运行并分解 Agent、环境和 Judge 方差。
- 关键行为回归采用非补偿性门禁，不能被其他任务的改善抵消。

## 9. 阈值确定

阈值不是通用常数。每个阈值都必须记录：
- 决策用途；
- 错误放行与错误拒绝的代价；
- 外部效标和目标基率；
- 统计不确定性；
- 选择数据与冻结测试数据；
- 灵敏度/特异度/校准/净效用；
- 适用的 Agent / Skill 类型和环境。

在没有上述证据时，状态为 NOT_VALIDATED，不得以“行业常用值”或 0.7 / 0.8 等经验值代替证明。

## 10. 最终验证结论

综合公式只能获得以下结论之一：
- **VALIDATED_FOR_SCOPE**：在明确的目标人群、用途和适用范围内，通过冻结验证协议。
- **PARTIALLY_VALIDATED**：部分维度/用途/域有证据，其他范围未验证。
- **NOT_VALIDATED**：证据不足或验证失败。
- **REJECTED**：模型存在不可接受的偏差、误判或不稳健问题。

报告必须公开模型版本、公式、参数/权重、训练/验证切分、统计分析代码、验证数据摘要、限制和复现步骤。VALIDATED_FOR_SCOPE 不能简写为“通用有效”。

## 11. 候选公式的显式数学形式

本节补充候选公式的可比较形式。所有公式均为研究候选，不代表选定、赋权或验证通过。

### 11.1 门禁与分项画像

对每个适用的关键门禁 G_j 记录 PASS / FAIL / UNKNOWN / NOT_APPLICABLE。综合分不能覆盖门禁失败。可报告结构为：

Q(D) = { GateStatus(D), MetricProfile(D), EvidenceUncertainty(D), OptionalComposite(D) }

若关键门禁为 FAIL，质量处置必须反映该失败；若关键门禁为 UNKNOWN / NOT_ASSESSED，则不能把综合结果解释为已验证或完整评价。门禁不是一个可由普通指标加权抵消的分数。

### 11.2 候选聚合模型

将各维度按事先定义、且经评审校准的锚点映射到 [0,1]，记为 z_j(D)。以下均为待比较模型：

**A. 加权算术模型**

Q_A(D) = Σ_j w_j z_j(D)，其中 w_j ≥ 0 且 Σ_j w_j = 1。

该模型允许完全补偿：某一维度的低分可能被其他维度高分抵消。仅在构念允许补偿、权重来源有依据且敏感性检验稳定时才可考虑。

**B. 加权几何模型**

Q_G(D) = Π_j z_j(D)^(w_j)，其中 z_j ∈ [0,1]。

该模型对低分维度惩罚更强，但仍需选择权重，且零值会使乘积为零。它不是天然更科学的模型，只是另一种补偿结构。

**C. 非补偿瓶颈模型**

Q_M(D) = min_{j ∈ J_c} z_j(D)，其中 J_c 是经构念论证的关键维度集合。

它强调最薄弱关键维度，但可能忽略其他维度的增量信息；只作为候选，不预设适用于所有质量构念。

**D. 分层/用途特定模型**

分别估计 IDA、Capability ERA 和 Regression ERA 的指标模型，不强行把它们汇总成一个共同分数。若产品需要摘要，只能在各自用途范围内形成经验证的汇总。

**E. 潜变量模型**

只有当指标理论上是同一潜在构念的反映性表现，且因子结构、局部独立、测量不变性等假设得到支持时才考虑。形成性指标不能因为相关性或方便而被强制拟合成单因子。

### 11.3 运行用途的独立公式

Capability 在适当 IRT 模型成立时，可计算测试信息：

I(θ) = Σ_i I_i(θ)，且条件标准误可表示为 SE(θ) = 1 / √I(θ)。

这描述指定能力区间的测量精度，不是离线质量总分。若 IRT 假设不成立，不使用该公式。

Regression 对已确认有效缺陷可报告：

Fault Detection Rate = detected confirmed faults / replayed valid confirmed faults。

该指标必须与 False Pass、False Fail、Failure Exposure、Flakiness 和执行成本并列报告。变异缺陷检出率单独报告，不替代真实故障检出。
